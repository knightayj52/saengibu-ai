생활기록부 AI 도우미

체크만 하면 교과·창체·행동특성 문장 초안을 만들어 주는 교사용 도구입니다.

  • 이 앱은 앱이 만든 시트와 선생님이 직접 고른 시트에만 접근합니다. 드라이브의 다른 파일은 볼 수 없습니다.
  • 학생 데이터는 선생님 본인의 Google Drive 스프레드시트에만 저장됩니다. 별도 서버가 없습니다.
  • 기존 구글시트 버전(v9)과 같은 시트를 그대로 씁니다. 시트에서 체크한 내용이 여기서도 보입니다.

개인정보 처리방침

데이터를 저장할 시트를 연결하세요

한 번 연결하면 이 브라우저에서 계속 기억하고, 다른 기기에서 로그인해도 마지막에 쓰던 시트를 자동으로 불러옵니다.

📂 쓰던 v9 시트가 있어요

🔑 Gemini API 키

키는 이 브라우저에만 저장되고 시트나 다른 곳으로 보내지 않습니다. 발급: aistudio.google.com/apikey (무료)

연결한 시트(⚙️설정 C14)에 API 키가 들어 있습니다.

켜면 다른 컴퓨터·태블릿에서 로그인했을 때 키를 다시 넣지 않아도 됩니다. 시트 내용에는 보이지 않지만, 이 시트 파일을 다른 사람과 공유하면 그 사람이 이 앱에서 내 키를 쓰게 될 수 있으니 공유할 시트라면 끄세요.

🤖 AI 모델 · 요금제

종료된 모델이 설정돼 있으면 권장 모델로 자동 교체됩니다.

🏫 학급 · 분량

이 설정들은 시트(⚙️설정)에 저장됩니다. 마무리 문장 설정만 웹앱 전용이고 나머지는 v9와 공유됩니다.

💾 백업

스프레드시트 파일 전체를 내 드라이브에 사본으로 저장합니다. 되돌리려면 아래 [다른 시트로 바꾸기]에서 그 사본을 고르면 됩니다.

🆕 새 학기 시작

지금까지의 결과를 📦 탭으로 보관하고, 결과와 체크를 비웁니다. 학생명단·개인 특성·설정·항목은 그대로 둡니다.

📄 연결된 시트

연결만 끊습니다. 시트 파일은 드라이브에 그대로 남습니다.

👥 학생명단

개인 특성은 선택 사항입니다. 적어 두면 같은 항목을 체크해도 학생마다 다른 문장이 만들어집니다. 이 칸의 글은 AI에 그대로 전달되므로 이름·연락처·건강 정보는 적지 마세요.

✨ AI 생성

체크한 내용으로 문장 초안을 만들어 결과 시트에 저장합니다. 이미 완료된 항목은 건너뛰고, 오류가 났던 항목만 다시 만듭니다.

생성 중에는 이 탭을 닫거나 다른 탭 뒤로 보내지 마세요. (브라우저가 숨은 탭의 작업을 늦춥니다)

📈 결과 확인 · 수정

생성된 문장을 읽고, 직접 고치거나 다시 만들 수 있습니다.

🔍 결과 유사도 검사

같은 과목·영역 안에서 학생끼리 문장이 지나치게 비슷한지 확인합니다.

📋 항목 설정

체크할 항목(성취기준·활동·문구)을 정합니다. 학기 초에 한 번 입력하면 됩니다. 저장하면 시트의 설정 탭에 기록되고 체크 화면에 반영됩니다.
