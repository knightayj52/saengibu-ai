영쌤클래스 · 크롬 확장 프로그램 0.2.1

검토한 문장을
나이스 입력란으로

교과·창체·행발의 한 과목·영역씩, 학생 번호와 이름이 모두 일치하는 빈칸을 채웁니다. 최종 저장은 선생님이 직접 합니다.

0.1 / 0.2를 설치하셨다면 먼저 업데이트

이번 0.2.1 버전은 이름 뒤의 (전입학) 표시를 구분하여 학생을 찾습니다. 원래 번호와 이름을 함께 대조하며, 파일에서 빠진 번호는 건너뜁니다. 또한 한 학생의 입력칸을 먼저 클릭해 열 위치를 확인한 다음, 번호순으로 다른 학생의 칸을 활성화하고 입력합니다. 찾지 못한 학생이 있으면 그 지점에서 중지합니다.

  1. 아래 새 ZIP을 받아 압축을 풉니다. 이번 ZIP은 폴더가 중첩되지 않으며, 압축을 푼 첫 폴더에 manifest.json이 있습니다.
  2. 크롬 주소창에서 chrome://extensions를 열고 기존 나이스 입력 도우미의 삭제를 누릅니다.
  3. 개발자 모드를 켜고 압축해제된 확장 프로그램을 로드합니다에서 새로 푼 neis-extension-v0.2.1 폴더를 선택합니다.
  4. 설치된 카드에 0.2.1이 보이는지 확인합니다. 기존 자동 입력 JSON 파일은 그대로 사용할 수 있습니다.

나이스에서 이미 입력한 내용이 있다면 먼저 확인 후 저장해 두세요. 확장 프로그램 업데이트를 위해 나이스를 새로고침할 필요는 없습니다.

1. 처음 한 번 설치

  1. 확장 프로그램 ZIP 받기를 누르고 압축을 풉니다.
  2. 크롬 주소창에 chrome://extensions를 입력합니다.
  3. 오른쪽 위 개발자 모드를 켜고 압축해제된 확장 프로그램을 로드합니다를 누릅니다.
  4. 압축을 푼 neis-extension-v0.2.1 폴더를 선택합니다. 이 폴더 안에 manifest.json이 바로 있습니다.
  5. 크롬의 퍼즐 아이콘에서 ‘영쌤클래스 · 나이스 입력 도우미’를 고정합니다.

학교 PC에서 확장 프로그램 설치가 제한된 경우 해당 PC에서는 이 방식으로 사용할 수 없습니다.

2. 앱에서 준비

  1. 생기부 AI 도우미 → NEIS 입력 → 크롬 자동 입력 · 시험 버전을 엽니다.
  2. 학년도·학년·반·학기와 과목/영역을 선택합니다.
  3. 문장을 검토한 뒤 자동 입력 파일 받기를 누릅니다. JSON은 엑셀 업로드가 아닌 이 도우미 전용 전달 파일입니다.

3. 나이스에서 채우기

  1. 나이스에서 정확한 학급과 과목/영역을 조회하고, 학생 한 명의 문장 입력칸 안을 한 번 클릭합니다. 이 칸으로 입력 열을 확인합니다.
  2. 확장 프로그램 아이콘을 누르고 받은 JSON 파일을 선택합니다.
  3. 현재 나이스 화면 대조를 누릅니다. 일치 학생과 문장을 미리 봅니다.
  4. 학급·학기·과목/영역은 현재 화면과 직접 대조하여 확인란에 체크합니다. 이 정보는 자동으로 확정하지 않습니다.
  5. 처음에는 첫 선택 학생 1명 채우기로 테스트합니다. 나이스 입력란의 문장과 바이트 표시가 함께 바뀌는지 확인합니다.
  6. 정상 반영을 확인했다면 확인란을 다시 체크하고 선택 학생 번호순 자동 입력을 누릅니다. 선택된 학생을 번호순으로 처리하며 기존 문장은 덮어쓰지 않습니다.
  7. 스크롤이 필요한 학생은 자동으로 탐색합니다. 찾지 못하거나 입력칸 활성화에 실패하면 해당 번호에서 멈춥니다. 입력 중에는 확장 프로그램 창을 열어 두세요. 최종 확인 후 나이스 저장 버튼을 직접 누릅니다.

현재 지원 범위

실제 학교 나이스에서 검증하기 전의 시험 버전입니다. 일반 HTML 표 또는 접근성 표에서 학생 번호·이름과 문장 입력 열을 확인할 수 있는 구조를 지원합니다. 칸을 클릭할 때 textarea가 만들어지는 편집기와 스크롤 시 행이 바뀌는 표를 처리하도록 보완했습니다. 캔버스 표, 번호/이름이 별도 표로 분리된 고정 열, 다른 출처의 프레임, 실제 클릭만 허용하는 특수 편집기는 인식하지 못할 수 있습니다.

인식 0명 또는 중복이 나오면 입력하지 않습니다. 이때 대조 결과 메시지와 학생 정보를 가린 화면을 알려주시면 화면에 맞는 추가 대응이 가능합니다. 입력란의 글자가 보이더라도 내부 저장 데이터 반영까지 보장하지 않으므로 1명 테스트가 먼저입니다.

자율·동아리 기록이 통합 표시되는 화면에서는 기존 문장 보존을 위해 빈칸만 채웁니다. 다른 영역 기록과의 자동 병합은 지원하지 않습니다.

기록 보관

확장 프로그램에는 외부 통신 코드가 없습니다. 불러온 기록은 크롬 세션 메모리에만 보관하고 ‘불러온 기록 지우기’로 제거합니다. 다운로드한 JSON에는 학생 이름과 문장이 들어 있으므로 사용 후 직접 정리해 주세요. 저장 완료 여부는 확장 프로그램이 판단하지 않습니다.
