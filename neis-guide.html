영쌤클래스 · 나이스 입력 도우미 BETA 0.4.0

검토한 문장을,
학생에 맞는 나이스 빈칸으로.

생활기록부 앱에서 완성한 문장을 학생 번호·이름으로 대조하여 채우는 크롬 확장프로그램입니다. 한 과목·영역씩 입력하고, 최종 확인과 나이스 저장은 선생님이 직접 합니다.

Chrome 웹 스토어에서 설치 ↗생기부 앱 열기

PC용 크롬에서 사용합니다. 미등록 배포이므로 스토어 검색 대신 위 설치 버튼을 이용하세요. 설치 창에서 사용자가 직접 추가를 승인합니다.

STEP 01 · 처음 한 번

크롬에 입력 도우미 설치하기

  1. 위 Chrome 웹 스토어에서 설치를 누릅니다. 이름이 ‘영쌤클래스 · 나이스 입력 도우미 BETA’인지 확인합니다.
  2. Chrome에 추가 → 확장 프로그램 추가를 누릅니다. ZIP 다운로드나 개발자 모드 설정은 필요하지 않습니다.
  3. 크롬 오른쪽 위 퍼즐 모양 확장프로그램 메뉴에서 입력 도우미의 핀을 눌러 고정합니다.
  4. 생기부 앱으로 돌아와 새로고침합니다. 앱의 NEIS 입력 → 연결 확인에서 ‘연결됨 · 버전 …’을 확인합니다.

생기부 앱과 나이스를 같은 크롬 프로필에서 사용하세요. 다른 PC에서는 먼저 설치 여부를 확인해야 합니다. 학교에서 확장프로그램 설치를 제한한 PC는 담당자에게 허용 여부를 확인하세요.

이전에 ZIP으로 수동 설치했다면?

나이스에서 작성 중인 내용을 먼저 확인·저장하고, 확장프로그램에서 작업 종료·기록 지우기를 누릅니다. 작업 중이던 나이스 탭을 닫은 뒤 chrome://extensions에서 기존 수동 설치본을 제거하고 스토어 버전을 설치하세요. 생기부 앱도 새로고침합니다. 두 설치본을 함께 켜두지 마세요.

STEP 02 · 생기부 앱

문장을 검토하고 보내기

  1. 생기부 앱에서 문장을 생성한 뒤, 관찰한 사실에 맞는지 읽고 필요한 부분을 수정·저장합니다.
  2. NEIS 입력을 열고 나이스 자동 입력 준비 · BETA에서 학년도·학년·반·학기를 확인합니다.
  3. 입력할 과목 또는 영역 한 가지를 고릅니다. 표시되는 전송 대상 수를 확인합니다.
  4. 문장·학급 정보를 검토했다는 확인란을 체크하고 나이스로 보내기를 누릅니다.

‘전달했습니다’는 확장프로그램에 기록을 보관했다는 뜻입니다. 아직 나이스에 입력하거나 저장한 상태는 아닙니다. 전달 후 15분 안에 다음 단계로 진행하세요. 만료되면 앱에서 다시 보내면 됩니다.

STEP 03 · 나이스

대조한 뒤 입력하고, 직접 저장하기

  1. 나이스에 직접 로그인하고 정확한 학급·학기·과목/영역을 조회합니다.
  2. 학생 한 명의 문장 입력칸 안을 한 번 클릭합니다. 이 칸을 기준으로 입력할 열을 확인합니다.
  3. 고정해 둔 입력 도우미 아이콘을 열고 현재 나이스 화면 대조를 누릅니다.
  4. 학년도·학년·반·학기·과목/영역과 학생별 문장을 확인합니다. ‘확인 불가’ 항목은 실제 나이스 화면을 보고 각각 체크합니다. ‘불일치’ 또는 ‘여러 값’이면 입력을 멈추고 화면을 바로잡은 뒤 다시 대조합니다.
  5. 처음 사용하는 화면에서는 첫 선택 학생 1명 채우기로 학생·문장·바이트 표시를 확인합니다.
  6. 정상이라면 확인란을 다시 체크하고 선택 학생 번호순 자동 입력을 누릅니다. 입력하는 동안 팝업을 열어 두고 학급·과목·탭을 바꾸지 않습니다.
  7. 입력 결과를 확인한 뒤 나이스의 저장 버튼을 직접 누릅니다. 처음 사용하는 화면에서는 저장 후 다시 조회하여 반영도 확인합니다.
  8. 작업을 마치면 입력 도우미의 작업 종료·기록 지우기를 누릅니다.
중간 번호가 빠져도 번호를 당기지 않습니다. 예를 들어 전송 자료에 8번이 없으면 7번 다음 9번을 찾습니다. 번호·이름이 일치하는 빈칸을 채우며, 기존 문장을 덮어쓰지 않습니다. 이름 뒤의 ‘(전입학)’ 표시는 이름과 구분합니다.

학교·화면 구조에 따라 인식이 달라질 수 있습니다. 기존 문장에 다른 영역의 문장을 자동으로 합치는 기능은 제공하지 않습니다. 입력 도우미는 교육부·교육청·나이스의 공식 제품이 아닙니다.

학교 밖에서 다른 인터넷이 막히면?

원격접속 후 생기부 앱을 열 수 없다면, 접속 전에 검토한 기록을 JSON 파일로 준비해 주세요. 나이스 자체의 접속 권한과 원격접속 환경은 선생님이 준비해야 합니다.

  1. 외부 인터넷을 사용할 수 있을 때 확장프로그램을 설치합니다.
  2. 생기부 앱의 NEIS 입력에서 과목·학급 정보를 확인하고 JSON 파일 받기 (외부 접속용)를 누릅니다.
  3. 원격접속 후 나이스에서 원하는 입력 화면을 열고 학생 한 명의 입력칸을 클릭합니다.
  4. 입력 도우미를 열어 준비한 JSON 파일을 선택합니다. 이후 화면 대조 → 입력 → 나이스에서 직접 저장 순서로 진행합니다.

JSON에는 학생 이름·번호·평가 문장이 들어 있으며 암호화되지 않습니다. 공개 링크·메신저 단체방에 올리지 말고, 학교의 자료 관리 기준에 따라 보관·삭제하세요. 원격접속 환경에서 확장프로그램 실행 자체를 막으면 이 방식도 사용할 수 없습니다.

막히는 부분이 있나요?

설치했는데 ‘연결을 확인하지 못했습니다’가 나와요.

생기부 앱을 새로고침하고 다시 연결 확인을 누르세요. 같은 크롬 프로필인지, 입력 도우미가 사용 중인지 확인합니다. 수동 설치본과 스토어 설치본을 함께 켜두었다면 수동 설치본을 제거하세요. 사이트 접근을 제한했다면 생기부 앱에서 실행할 수 있도록 설정을 확인합니다.

나이스로 보내기 버튼이 보이지 않아요.

문장 생성·검토를 마친 뒤 NEIS 입력으로 이동하세요. 완료된 결과가 없을 때는 설치 안내만 표시됩니다. 연결된 시트에 완료 문장이 있는지 확인하세요.

‘임시 기록이 만료되었습니다’라고 나와요.

앱에서 나이스로 보내기를 다시 누르거나 JSON 파일을 다시 불러오고 화면 대조부터 시작합니다. 이미 나이스에 입력한 문장은 지워지지 않으며 기존 문장이 있는 칸은 건너뜁니다.

학급·과목이 ‘확인 불가’ 또는 ‘불일치’예요.

확인 불가는 화면 값을 자동으로 읽지 못한 상태이므로 선생님이 항목별로 직접 대조합니다. 불일치는 실제로 읽은 값이 다르다는 뜻입니다. 앱과 나이스의 학급·학기·과목을 바로잡고 다시 보내거나 대조하세요.

0명으로 나오거나 마지막 학생이 선택되지 않아요.

전송 자료에 해당 학생의 결과가 포함됐는지 확인합니다. 나이스의 문장 입력칸 안을 먼저 클릭한 뒤 다시 대조하세요. 기존 기록, 이름·번호 불일치, 중복 입력란 또는 지원되지 않는 표 구조는 입력을 막을 수 있습니다. 오류 메시지와 학생정보를 가린 화면으로 문의해 주세요.

입력 중 멈췄어요. 처음부터 덮어쓰나요?

이미 채운 문장을 확인한 뒤 다시 대조하세요. 기존 문장은 덮어쓰지 않습니다. 계속 진행하려면 새 대조 결과에서 필요한 학생을 선택합니다. 화면 변경이나 입력칸 인식 실패 시 그 지점에서 멈출 수 있습니다.

업데이트할 때마다 다시 설치해야 하나요?

스토어에서 설치한 확장프로그램은 Chrome의 업데이트 기능으로 새 게시 버전을 받습니다. 반영에는 시간이 걸릴 수 있습니다. ZIP으로 수동 설치한 시험 버전은 스토어 버전으로 한 번 전환해야 합니다.

작업 후 기록 관리

확장프로그램의 입력 기능은 학생 기록을 개발자 서버나 AI 서버로 보내지 않습니다. 기록은 해당 크롬의 세션 저장소와 실행 중인 화면에서 처리합니다. 생기부 앱의 AI 생성·구글 드라이브 저장은 별도 기능입니다.

  • 불러오기·전달 후 15분 동안 대조·입력하지 않으면 만료됩니다. 대조·입력 시 15분 연장됩니다.
  • 작업 종료·기록 지우기는 현재·대기 기록과 연결된 화면의 작업용 사본을 정리합니다. 정리 실패가 표시되면 해당 나이스 탭을 닫으세요.
  • 절전 등으로 실제 정리가 늦어져도 만료된 기록의 재사용은 차단합니다.
  • 나이스에 채운 문장, 생기부 앱의 원본과 다운로드한 JSON은 별도로 관리됩니다.
