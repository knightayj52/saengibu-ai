나이스 입력 도우미
개인정보 처리 안내

영쌤클래스 · 적용일: 2026년 10월 14일 · 확장프로그램 0.3.1

적용 범위와 목적

이 안내는 ‘영쌤클래스 · 나이스 입력 도우미 BETA’ 크롬 확장프로그램에 적용됩니다. 교사가 검토한 문장을 학생 번호·이름으로 대조하고 나이스의 빈 입력란에 채우는 기능만 제공합니다. 교육부·교육청·나이스의 공식 제품이 아닙니다. 생기부 웹앱의 AI 생성, 구글 로그인·드라이브 기능 및 나이스 서비스 자체의 처리는 이 확장프로그램 안내의 범위에 포함되지 않습니다.

처리하는 정보

  • 사용자가 JSON 파일 또는 생기부 앱의 ‘나이스로 보내기’로 전달한 학생 이름·번호·평가 문장, 학년도·학년·반·학기·과목/영역.
  • 사용자가 화면 대조를 실행한 현재 나이스 탭의 주소, 화면에 표시된 학생 번호·이름·기존 문장 및 입력칸 상태.
  • 입력 중 화면 변경을 감지하기 위한 표시된 선택값·탭·제목 등 화면 정보. 비밀번호 입력값과 숨김 입력값은 이 비교에서 제외합니다.

전체 방문 기록·쿠키·로그인 자격증명·결제 정보는 기능 목적으로 수집하지 않습니다. 입력되는 평가 문장의 내용은 사용자가 선택합니다.

사용·전달과 보관

기록은 해당 크롬의 chrome.storage.session과 실행 중인 화면 메모리에서 처리합니다. 확장프로그램 자체에는 기록을 개발자 서버, 분석·광고 서비스 또는 AI API로 보내는 기능이 없으며, 개발자는 자동으로 기록을 받거나 열람하지 않습니다.

생기부 앱과 확장프로그램 사이의 전달은 같은 브라우저 안에서 이루어집니다. 사용자가 입력을 실행하면 문장이 나이스 페이지에 전달되고, 이후 페이지 자체의 처리와 교사가 실행한 저장은 나이스 서비스에 따릅니다. 확장프로그램은 저장 버튼을 누르지 않습니다.

브라우저 세션이 종료되면 확장프로그램의 세션 보관 기록은 지워집니다. 확장프로그램에서 ‘불러온 기록 지우기’를 눌러 보관된 현재·대기 기록을 삭제할 수도 있습니다. 화면 변경 감지용 정보는 해당 페이지 실행 메모리에서만 사용합니다.

이 동작은 다운로드한 JSON, 생기부 앱에 저장된 기록 또는 나이스에 이미 입력·저장된 내용을 삭제하지 않습니다. JSON 파일은 사용자가 직접 관리·삭제해야 합니다.

권한 사용

  • activeTab: 사용자가 확장프로그램을 연 현재 탭에 일시적으로 접근합니다. 실제 입력 기능은 HTTPS 나이스 도메인에서만 실행합니다.
  • scripting: 현재 나이스 화면의 번호·이름·입력칸을 대조하고 검토한 문장을 채우는 동봉 스크립트를 실행합니다.
  • storage: 사용자가 전달한 기록을 브라우저 세션 동안 보관합니다. 계정 간 동기화 저장은 사용하지 않습니다.
  • 생기부 앱 경로 접근: https://knightayj52.github.io/saengibu-ai/ 에서 연결 확인과 사용자가 보낸 기록 수신에만 사용합니다.

제3자 제공과 제한된 사용

처리하는 데이터를 판매하거나 광고, 신용 평가 또는 대출 목적에 사용하지 않습니다. 위에서 설명한 사용자가 요청한 나이스 입력 외의 목적으로 제3자에게 제공하지 않습니다. 데이터 사용은 표시된 단일 기능에 한정하며 Chrome 웹 스토어 사용자 데이터 정책의 제한된 사용 요구사항을 준수합니다.
