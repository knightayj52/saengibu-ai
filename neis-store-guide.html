Chrome 웹 스토어 제출 안내

영쌤클래스 · 나이스 입력 도우미 BETA · 제출 준비용 0.4.0 · 2026-10-29 · 재심사 전

1. 테스트 후 기존 항목에 새 버전 업로드

0.4.0 제출용 ZIP 다운로드 · 로컬 설치·테스트 안내

현재 승인된 0.3.1을 먼저 게시할 필요는 없습니다. 0.4.0을 로컬에서 테스트한 뒤, 개발자 대시보드의 기존 나이스 입력 도우미 항목 → 패키지 → 새 패키지 업로드에서 ZIP을 선택합니다. 새 항목을 만들지 않습니다. 제출용 ZIP은 압축을 풀지 않습니다.

게시 준비 상태에서 업로드가 비활성화되어 있다면 ‘상태’ 화면의 현재 버전·사용 가능한 작업을 확인한 뒤 처리하세요. 기존 버전을 먼저 게시하여 우회하지 마세요. 이 안내는 자동으로 심사를 취소하거나 제출하지 않습니다.

아래 등록정보·개인정보·alarms 권한 사유를 갱신하고 새 버전을 심사에 제출합니다. 자동 게시 해제를 유지하면 승인 후 직접 게시할 수 있습니다. 0.3.1의 승인이 새 코드의 승인을 의미하지는 않습니다.

데이터 판매·목적 외 이용·신용 평가 관련 확인 문구는 실제 동작과 일치하는지 읽은 뒤 체크합니다. 문구나 선택지가 이 안내와 다르면 현재 화면을 기준으로 확인합니다.

3. 배포 대상 확인

  1. 소수의 지정 계정으로 시험하려면 비공개(Private)를 선택합니다. 링크로 설치하도록 하려면 미등록(Unlisted)을 선택할 수 있지만 링크를 아는 사람의 접근을 제한하는 방식은 아닙니다. 실제 배포 설정을 확인하세요.
  2. 비공개를 선택한 경우 계정의 신뢰할 수 있는 테스터 목록에 본인과 시험 사용자 구글 계정을 등록합니다.
  3. 등록정보·개인정보·테스트 안내를 저장합니다.
  4. 우선 본인의 실제 나이스에서 전입학 학생과 직접 전달 기능을 확인하고 초안을 검토합니다.
  5. 준비가 끝나면 ‘심사를 위해 제출’. 검토 후 공개를 직접 결정하려면 자동 게시 옵션을 해제합니다.

비공개도 심사를 받습니다. 심사 통과는 실제 나이스 입력·저장 정확성의 보증이 아닙니다. 0.4.0의 스토어 제출·게시는 아직 수행하지 않았습니다.

4. 승인 후 게시

새 버전의 승인과 실제 나이스 테스트 결과를 확인한 뒤 게시합니다. 기존 항목을 업데이트하므로 동일한 확장프로그램 ID와 스토어 주소를 유지합니다. 비공개에서는 허용된 테스터 계정으로 설치해야 합니다.
