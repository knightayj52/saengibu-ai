1. 새 항목에 ZIP 업로드

제출용 ZIP 다운로드 · 이미지·예시 자료 묶음 다운로드

개발자 대시보드에서 ‘새 항목’ 또는 ‘Add new item’ → 제출용 ZIP 선택 → 업로드. 제출용 ZIP은 압축을 풀지 않습니다. 이미지 자료 묶음은 압축을 풀어 아래 파일을 개별 업로드합니다.

계정 설정에서 개발자 이메일 인증이나 2단계 인증을 요구하면 해당 안내를 완료하세요. 현재 단계는 초안 준비이며 실제 심사 제출은 대시보드에서 진행합니다.

데이터 판매·목적 외 이용·신용 평가 관련 확인 문구는 실제 동작과 일치하는지 읽은 뒤 체크합니다. 문구나 선택지가 이 안내와 다르면 현재 화면을 기준으로 확인합니다.

3. 비공개 시험 배포 설정

  1. 배포 대상: 비공개(Private). 한국을 포함한 필요한 지역 선택. 무료로 배포.
  2. 계정의 신뢰할 수 있는 테스터 목록에 본인과 시험 사용자 구글 계정을 등록합니다.
  3. 등록정보·개인정보·테스트 안내를 저장합니다.
  4. 우선 본인의 실제 나이스에서 전입학 학생과 직접 전달 기능을 확인하고 초안을 검토합니다.
  5. 준비가 끝나면 ‘심사를 위해 제출’. 검토 후 공개를 직접 결정하려면 자동 게시 옵션을 해제합니다.

비공개도 심사를 받습니다. 심사 통과는 실제 나이스 입력·저장 정확성의 보증이 아닙니다. 아직 실제 사용자 계정으로 이 제출을 완료하지 않았습니다.

4. 항목 ID 전달

ZIP 업로드 후 생성되는 확장프로그램 ID(알파벳 32자) 또는 스토어 항목 주소를 알려주시면 생기부 앱의 정식 설치 연결에 사용할 수 있습니다. 비밀번호·인증 코드·결제 정보는 필요하지 않습니다. 비공개에서는 허용된 테스터 계정으로 설치해야 합니다.
