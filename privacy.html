개인정보 처리방침

생활기록부 AI 도우미 (웹앱) · 시행일 2026년 10월 7일

한 줄 요약
이 앱에는 서버가 없습니다. 제작자(영쌤클래스)는 선생님의 계정 정보도, 학생 정보도, API 키도 받거나 보관하지 않습니다. 모든 데이터는 선생님 본인의 Google Drive와 지금 쓰는 브라우저 안에만 있습니다.

1. 앱이 다루는 정보와 저장 위치

정보저장 위치설명
학생명단, 체크 내용, 생성된 문장선생님 본인의 Google Drive 스프레드시트브라우저가 Google Sheets에 직접 읽고 씁니다. 제작자를 거치지 않습니다.
Gemini API 키지금 쓰는 브라우저(localStorage)이 기기의 이 브라우저에만 저장됩니다. 시트나 다른 곳으로 보내지 않습니다.
Google 로그인 토큰, 계정 이메일·이름지금 쓰는 브라우저(localStorage)로그인 유지와 화면 표시에만 씁니다. 토큰은 약 1시간 뒤 만료됩니다.
아직 시트에 저장되지 못한 체크·메모지금 쓰는 브라우저(localStorage)인터넷이 끊기거나 로그인이 만료된 순간의 입력을 잃지 않기 위한 임시 보관입니다. 시트에 저장되는 즉시 지워집니다.
연결한 시트의 ID지금 쓰는 브라우저(localStorage)다음에 열 때 같은 시트를 다시 불러오기 위한 값입니다.

2. Google 계정 권한

이 앱은 Google 권한 가운데 drive.file 하나만 요청합니다. 이 권한으로는 앱이 직접 만든 파일과 선생님이 파일 선택 창에서 직접 고른 파일에만 접근할 수 있습니다. 드라이브의 다른 파일은 보거나 고칠 수 없습니다.

이 앱이 Google API로 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다. 받은 데이터는 선생님에게 화면으로 보여 주고 선생님의 시트에 저장하는 데에만 쓰며, 광고·판매·제3자 제공·AI 학습에 쓰지 않습니다.

3. AI 생성 시 외부로 전송되는 내용

문장을 생성할 때, 브라우저가 선생님의 API 키로 Google Gemini API에 요청을 직접 보냅니다. 이 요청에는 체크한 항목, 활동 내용, 선생님이 적은 학생 개인 특성 메모가 들어갑니다.

  • 앱은 학생 이름과 번호를 Gemini 요청에 넣지 않습니다. 다만 선생님이 특성 메모나 활동 내용 칸에 직접 적은 글은 그대로 전송되므로, 그 칸에는 이름·연락처·건강 정보 같은 민감한 내용을 적지 않기를 권장합니다.
  • 전송된 내용의 처리는 Google의 Gemini API 약관을 따릅니다. 무료 요금제 키는 입력 내용이 Google의 서비스 개선에 쓰일 수 있다고 안내되어 있으니, 사용 전에 약관과 소속 학교·교육청 지침을 확인해 주세요.

4. 수집하지 않는 것

  • 제작자가 운영하는 서버·데이터베이스가 없습니다.
  • 방문 통계, 광고, 추적 도구(쿠키 포함)를 쓰지 않습니다.
  • 앱은 GitHub Pages에서 제공됩니다. 페이지를 여는 과정에서 GitHub가 접속 기록(IP 주소 등)을 남길 수 있으며, 이는 GitHub 개인정보 처리방침을 따릅니다.

5. 삭제와 연결 해제

  • 학생 데이터 — Google Drive에서 해당 스프레드시트를 삭제하면 됩니다.
  • 브라우저에 저장된 값 — 앱에서 로그아웃하면 로그인 정보가 지워지고, API 키도 함께 지울지 선택할 수 있습니다. 브라우저의 사이트 데이터 삭제로도 모두 지워집니다.
  • Google 계정 연결 — Google 계정 → 서드 파티 앱 및 서비스에서 이 앱의 접근 권한을 언제든 해제할 수 있습니다.

6. 사용 시 유의사항

  • 여럿이 쓰는 컴퓨터에서는 사용 후 반드시 로그아웃하고 API 키를 지워 주세요.
  • AI가 만든 문장은 초안입니다. 사실 여부와 표현은 선생님이 확인한 뒤 사용해 주세요.
